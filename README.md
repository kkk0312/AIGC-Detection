基于“预训练特征提取器+定制化分类器”统一框架的**通用AIGC检测系统**，专为政务司法、学术诚信、社交媒体内容安全等场景打造，实现从单模态到全模态检测的技术跨越。


## 📌 项目背景

随着生成式人工智能（AIGC）技术的爆发，AI生成内容的滥用引发严峻的安全与诚信危机，现有检测系统存在三大核心瓶颈：
- **模态覆盖不全**：多数系统仅支持文本/图像检测，无法处理视频、音频等动态模态（如腾讯朱雀大模型仅支持图文）；
- **跨模型泛化弱**：传统模型依赖特定生成模型（如GAN）的伪影特征，面对扩散模型等新型生成工具时检测失效；
- **短文本检测缺陷**：主流系统（如朱雀大模型）无法检测350字以下短文本，难以应对社交媒体评论、即时通讯等场景。

本项目针对上述痛点，构建“天眼AI”全模态检测系统，为AI诈骗防范、学术打假、虚假信息治理提供技术支撑。


## 🌟 核心特性

### 📊 全模态检测覆盖
- 支持**文本、图像、视频、音频**四大模态独立检测，解决传统系统“模态割裂”问题；
- 针对各模态特性设计专属技术链路：文本用RoBERTa-MPU、图像用CLIP:ConvNext、音视频用CrossModal-STF-Fusion；
- 统一Web界面实现“一站式”检测。

### 🌐 跨模型强泛化能力
- 采用**冻结预训练特征提取器**（CLIP:ConvNext、RoBERTa-MPU、WavLM等），避免模型过拟合特定生成模型伪影；
- 聚焦真实与AI生成内容的**本质差异**（语义一致性、结构合理性），而非表面特征；
- 跨域测试中，图像/文本/视频检测准确率较主流方案平均提升1.13%-1.46%，音频EER降低1.13%。

### 📝 短文本检测突破
- 创新“RoBERTa-MPU + Conformer-MLP”架构：RoBERTa-MPU提取字/词/句多尺度语义特征，解决短文本语义稀疏问题；
- Conformer-MLP通过动态注意力聚焦关键token（疑问词、情感词），强化“逻辑断层”“语义跳跃”等AI生成特征识别；
- 支持10字以上短文本检测，准确率达99.03%，填补行业技术空白。

### 🎞️ 跨模态时序融合
- 创新设计**CrossModal-STF-Fusion模块**，实现音视频“时空-频域——单帧-时序——音频-画面”特征联合建模；
- 三重核心机制：跨模态注意力对齐（视觉-听觉特征互补）、Conformer时序依赖挖掘、FFTConv频域伪影捕捉；
- 视频检测准确率达97.11%，较F3-Net等主流模型提升1.60%。

### 🚀 自动化高效流程
- 全流程自动化：从文件上传→预处理→模型检测→结果输出，无需人工干预；
- 支持多格式输入：文本（docx/txt）、图像（jpg/png）、视频（mp4/mov）、音频（mp3/wav/flac）；
- 检测结果可视化：输出AI生成概率及置信度，支持PDF/CSV格式导出。


## 🛠️ 技术架构

### 核心技术栈
| 模块                | 核心组件                                                                 |
|---------------------|--------------------------------------------------------------------------|
| 特征提取器          | CLIP:ConvNext（图像）、RoBERTa-MPU（文本）、CLIP:ViT（视频帧）、WavLM（音频） |
| 分类器/融合模块     | Conformer-MLP（图文）、CrossModal-STF-Fusion（音视频）、Conformer-FFTConv-P（音频） |
| 深度学习框架        | PyTorch 2.4.1+cu124、TorchVision 0.19.1+cu124                            |
| 前后端开发          | React（前端）、Flask（后端微服务）                                        |
| 部署方式            | Docker容器化、端云协同（规划中）                                          |

### 检测流程
1. **数据预处理**：图像统一分辨率、文本清洗特殊字符、视频抽帧标准化、音频归一化采样率；
2. **多模态特征提取**：冻结预训练模型提取各模态通用特征，避免过拟合特定生成模型；
3. **特征融合/分类**：针对不同模态调用专属分类器（如Conformer-MLP、CrossModal-STF-Fusion）；
4. **结果输出**：计算AI生成概率，生成可视化报告，支持多格式导出。


## 🚀 快速开始

### 🔧 环境准备
```bash
# 克隆项目
git clone https://github.com/username/tiyan-ai-aigc-detector.git
cd tiyan-ai-aigc-detector

# 安装依赖（关键依赖见requirements.txt）
pip install -r requirements.txt

```

### 🖥️ 系统启动
```bash
# 1. 启动后端服务（Flask）
cd backend
python app.py
# 后端服务默认运行在 http://localhost:5000

# 2. 启动前端界面（React）
cd frontend
npm install  # 安装前端依赖（首次运行需执行）
npm start
# 访问 http://localhost:3000 进入Web界面
```

### 📝 使用步骤
1. 打开Web界面，选择检测模态（文本/图像/视频/音频）；
2. 上传文件；
3. 点击“开始检测”，系统自动执行预处理与模型推理；
4. 查看检测结果（AI生成概率、置信度）。


## 🔍 模型原理与创新点

### 1. 统一检测框架
采用“**预训练特征提取器 + 定制化分类器**”架构，冻结预训练模型参数，仅训练分类器：
- 优势：避免模型学习特定生成模型的“指纹”特征，实现“生成模型无关”的通用检测；
- 适配性：针对不同模态灵活替换提取器（如文本用RoBERTa-MPU，图像用CLIP:ConvNext）。

### 2. 各模态核心模型
| 模态   | 架构                                  | 核心创新点                                                                 |
|--------|---------------------------------------|----------------------------------------------------------------------------|
| 图像   | CLIP:ConvNext + Conformer-MLP         | CLIP:ConvNext捕捉全局语义+局部细节，Conformer-MLP融合卷积与自注意力          |
| 文本   | RoBERTa-MPU + Conformer-MLP           | RoBERTa-MPU多尺度语义提取，解决短文本稀疏问题                              |
| 视频   | CLIP:ViT + WavLM + CrossModal-STF-Fusion | 跨模态注意力对齐，时空-频域特征联合建模                                    |
| 音频   | WavLM + Conformer-FFTConv-P           | WavLM捕捉长时依赖，FFTConv挖掘频域伪影                                    |

### 3. 关键创新模块：CrossModal-STF-Fusion
- **跨模态注意力交互**：以视频特征为Query，音频为Key/Value，实现视觉-听觉细粒度对齐；
- **时空域分支**：Conformer模块建模视频帧时序依赖，捕捉动态伪造痕迹；
- **频域分支**：FFTConvLayer转换特征至频域，挖掘音视频周期性频谱异常；
- **注意力池化**：动态聚焦关键特征，抑制冗余信息，提升泛化能力。


## 📈 实验测试分析

### 测试数据集
- 图像：DICIX赛题数据集、Universal Fake Image数据集；
- 文本：HC3-EN/ZH（含短文本拓展）、DeepSeek生成跨域数据集；
- 视频：Celeb-DF-v2、DH、DFDC；
- 音频：ASVspoof 2019/2021（含深度伪造语音）。

实验验证：系统在全模态检测精度、跨域泛化能力、短文本处理上均显著优于现有方案。
